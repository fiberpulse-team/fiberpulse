FTTH KPIs Sheet — Data Import

Paste the entire sheet (all months) in one go. Each month's title and any repeated header rows are detected automatically. If the time is entered as 16:20 only, it is combined with the Date column to form the full timestamp. Pasting the same Ticket # again updates the existing ticket instead of creating a duplicate, and your Type, Delay Reason and Remark are preserved. For new tickets, if Issue/Working contains "Outage" or "Mistakenly Ticket Generated", the Delay Reason is set automatically.

FTTH Work Report Sheet — Data Import

Select all in the FTTH Work Report (team daily activity) sheet, copy, and paste here. This updates the Daily Activity dashboard.
